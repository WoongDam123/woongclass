# woongclass

LLM이 직접 쓰고 관리하는 개인 지식 위키(LLM Wiki)입니다.

사람은 자료를 모으고 질문을 던지고, LLM은 자료를 읽어 위키 페이지를 만들고, 서로 연결하고, 최신 상태로 유지합니다.

## 구조

```
woongclass/
├── CLAUDE.md          # 스키마: LLM이 위키를 관리하는 규칙
├── raw/               # 원본 자료 (읽기 전용, LLM은 수정하지 않음)
│   └── assets/        # 이미지·첨부 파일
└── wiki/              # LLM이 작성·관리하는 마크다운 페이지
    ├── index.md       # 전체 페이지 목록 (카탈로그)
    ├── log.md         # 작업 기록 (시간순, 추가만)
    ├── overview.md    # 위키 전체 요약
    ├── sources/       # 원본 자료별 요약 페이지
    ├── concepts/      # 개념·주제 페이지
    ├── entities/      # 사람·기관·교재 등 고유 대상 페이지
    └── analyses/      # 질문에 대한 답변·비교·분석 결과
```

## 사용법

1. **자료 넣기(Ingest)**: `raw/`에 자료를 넣고 "이 자료 위키에 반영해줘"라고 말합니다.
2. **질문하기(Query)**: 위키 내용을 바탕으로 질문합니다. 쓸 만한 답은 `wiki/analyses/`에 저장합니다.
3. **점검하기(Lint)**: "위키 점검해줘"라고 하면 모순, 깨진 링크, 고아 페이지, 빠진 개념을 찾아 정리합니다.

[Obsidian](https://obsidian.md)으로 이 폴더를 열면 페이지 간 연결을 그래프로 볼 수 있습니다.
